# Music Trainer 🎸🎹

אפליקציית לימוד נגינה אישית (PWA) – גיטרה, פסנתר, תיאוריה ואימון שמיעה, בעברית.

## מה יש בפנים
- **מבחן רמה אדפטיבי** – שאלון היכרות קצר, ואחריו מבחן שמתאים את הקושי לתשובות (staircase) בארבעה תחומים: תיאוריה, שמיעה, גיטרה ופסנתר. כולל תרגילים שמקשיבים לכלי דרך המיקרופון.
- **מסלולים מדורגים** – תיאוריה ושמיעה משותפות לשני הכלים, ומסלול טכניקה נפרד לגיטרה ולפסנתר. 5 רמות בכל מסלול, ~45 שיעורים.
- **תרגילים אינסופיים** – כל שאלה נוצרת מחדש בכל פעם (גנרטורים), כך שאי אפשר "לשנן" תשובות.
- **תרגול אינטראקטיבי** – מקלדת וירטואלית, צוואר גיטרה, חמשה, דיאגרמות אקורדים.
- **זיהוי דרך מיקרופון** – זיהוי תו (YIN) וזיהוי אקורד (התאמת כרומה עם תבנית הרמוניות).
- **תרגול חכם** – מעדיף את המיומנויות החלשות ואת מה שלא תורגל מזמן.
- **כלים** – מכוון, מקלדת וצוואר חופשיים, ספריית אקורדים.
- הכל נשמר מקומית בטלפון; עובד גם אופליין אחרי טעינה ראשונה.

## הרצה
```bash
npm install
npm run dev      # פיתוח (נגיש גם מהטלפון ברשת המקומית)
npm test         # בדיקות
npm run build    # בנייה ל-dist/
```

להתקנה בטלפון: לפתוח את האתר בדפדפן → "הוסף למסך הבית". המיקרופון דורש HTTPS (או localhost).

## מבנה
- `src/theory` – תאוריה: תווים, מרווחים, סולמות, אקורדים, איות נכון.
- `src/engine/generators.ts` – כל סוגי התרגילים לפי תחום ורמה.
- `src/engine/placement.ts` – לוגיקת מבחן הרמה.
- `src/data/curriculum.ts` – השיעורים וההסברים.
- `src/audio` – סינתיסייזר (פסנתר + Karplus-Strong לגיטרה), זיהוי גובה ואקורדים.
